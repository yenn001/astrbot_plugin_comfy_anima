默认创作偏好：

- 清晰、稳定、角色连续性优先于堆砌信息。
- 普通英文标签只保留可见证据；同义词只留一个。
- 景别决定细节：肖像看面部受光与表情，半身看手势与布料，全身看重心与接触，
  环境看空间层次与主光。
- 可见性优先：点名要看的部位或服饰被外层衣物遮住时，用能露出它的构图与动作
  （掀起 / 撩开 / 褪下 / 敞开）并写出对应可见性 tag（skirt lift、clothes lift、
  dress lift、undressing、partially undressed），不得只描述被遮住的穿着状态；
  点名局部时优先半身或局部特写。
- 一组主光加一组辅助或轮廓光；不叠加互相竞争的时间与光源。
- 简单肖像可以很短；华丽要求才提高信息密度。
- 自然语言句只复述关键锚点，不新增事实。

Anima 自然语言提示词公式：
- 完整英文句子：谁 + 外观 DNA + 服装/状态 + 动作 + 表情 + 地点 + 镜头 +
  光效氛围；
- tag 串是成图质量的主体，不少于 20 个，按槽位凑齐：身份 ≥3、服装（含饰品，
  从上到下）≥5、动作 ≥2、镜头 ≥2、场景 ≥2、主光 ≥2；只设下限，不设上限；
- 允许 Danbooru 词作锚点；禁止权重符号；不足时从可见事实继续补，
  不得用无信息量的填充词凑数。
- 角色 DNA 六锚点必须覆盖：发色、发型（含长度与位置）、刘海、瞳色、脸型、
  肤色/体型。
- 人数预算：N=1 ≤150 词/人，N=2 ≤90 词/人，N≥3 ≤70 词/人，无下限。
- 最终提示词 soft cap 800 token / hard cap 1200 token；不恢复 2000 字符硬锁。
- 摄像机三问：在哪 / 谁的眼睛 / 什么角度；不要连续重复“正面 + 半身 + 中景”。
- 跨图连续性：每张图从上一张终点开始；状态只递增，重置需明确触发。
- 证据纪律：只使用已验证 LoRA 名称与角色 canonical；不编造事实。
