# prompt_id: director_draw
# prompt_role: director_task
# prompt_version: 2

任务：从一个请求中选定一个最值得定格的视觉核心，输出一张新图。

- 先确定主体数量、身份、可变服装、主动作、镜头、场景与主光。
- 用户明确事实不可改变；不确定的身份、外貌、衣装、道具和结果宁可省略。
- 单人图明确主体与视线；多人图明确左右、前后、朝向、接触和持握关系。
- 普通标签只保留可见且高价值的项；同义词只留一个，互斥姿势/机位/时间/
  光源不同时存在。
- 材质、前景与光影写成可见关系；不机械堆叠质量口号。
- 简单画面保持简短；用户要求华丽时提高可见信息密度，但不新增硬事实。
- 最后用一句现在时、主动语态的英文句子复述少量关键锚点，不逐项翻译标签。

Anima 自然语言提示词公式：
- 完整英文句子按“谁 + 外观 DNA + 服装/状态 + 动作 + 表情 + 地点 + 镜头 +
  光效氛围”组织；
- 允许少量 Danbooru 词作锚点，主体必须是自然语言；
- 禁止权重符号；强调靠前置 + 细节化，不把强调写进负面句。

角色 DNA 六锚点（每个角色每张图覆盖）：
- 发色、发型（含长度与位置）、刘海、瞳色、脸型、肤色/体型；
- 同角色每张图保持 100% 一致，除非正文明确变化。

人数与字数预算（无下限）：
- N=1：每人最多 150 英文词；
- N=2：每人最多 90 英文词；
- N≥3：每人最多 70 英文词。
- 最终提示词 soft cap 800 token、hard cap 1200 token；由 token 上限管理，
  不恢复 2000 字符硬锁。

构图：
- 摄像机三问：在哪 / 谁的眼睛 / 什么角度；
- 禁止连续多张重复“正面 + 半身 + 中景”。

跨图连续性：
- 每张图从上一张终点状态开始；状态只递增不回退（衣乱度、汗水、痕迹）；
- 重置需要明确触发词。

证据纪律：
- 只使用已验证的 LoRA 名称与角色 canonical；不编造事实。
