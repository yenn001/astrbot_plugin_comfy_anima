# ComfyAnima 进阶指南

写给已经能用基础命令、想搞懂“它到底怎么工作 / 为什么出问题”的人。
只讲现象、机制和处置，不讲内部术语。

> 下文用 **角色A** 指代任意已绑定角色；实际使用时把角色A换成你的角色名
> （比如达妮娅，日常叫娅娅）即可。

---

## 1. 一次出图，插件在幕后做了什么

以“角色A早上好呀，检查穿着了！（画出来）”为例：

```text
1. 意图判断   —— 判断这句话是闲聊还是想出图（本地向量优先，LLM 兜底仲裁）
2. 证据收集   —— 查本地 Danbooru 索引（124万标签）和 LoRA 库，验证要用的词真实存在
3. 导演扩写   —— 把你的话 + 验证过的标签，组织成完整画面描述
4. 角色绑定   —— 确认“角色A = 哪个 Danbooru 身份 = 哪个 LoRA 文件”，挂载并注入触发词
5. 机器校验   —— 标签必须真实存在、数量/长度达标、清单一致，不合格直接拦下
6. 提交 ComfyUI
```

每一步的规则：

| 步骤 | 什么情况会出图 | 什么情况不出 |
|---|---|---|
| 意图判断 | “（画出来）”“画一张”“来一张”等明确表达 | “不要画了”“明天再画”等否定/推迟 |
| 机器校验 | 全部通过 | 标签不存在 / 超长 / 清单不一致 |

## 2. 三个判断后端，怎么选

设置里的“意图判断后端模式”：

| 模式 | 行为 | 适合 |
|---|---|---|
| `rule` | 关键词判定，0 消耗 | 只要明确说“画”就出图 |
| `local` | Embedding + Rerank 语义判断（需配 bge-m3 / bge-reranker） | 不想依赖在线 |
| `online` | 独立 LLM 三分类 | 最准，但每条消息有开销 |
| `auto`（推荐） | 本地优先，没把握才问 LLM，LLM 说画就画 | 省钱与准确兼顾 |
| `both` | 本地 + 在线都跑，结论冲突时保守 | 最严格 |

补充规则：
- “（画出来）”这种**动作+交付**组合句式直接放行；但“不要画了”“明天再画”不会；
- 本地说“不画”而在线 LLM 说“画”时，**以在线语义判定为准**（向量的锚点是给 Bot
  回复设计的，对用户命令天然偏保守）；
- 本地发现“明天/先不”等推迟线索时，保守不出图，在线也推翻不了。

## 3. 角色 LoRA：身份是怎么认定的

角色像不像，取决于绑定链是否完整：

```text
你说“角色A” → 语义索引识别别名 → LoRA 文件 → Danbooru exact 身份绑定 → 激活词
```

举个实例（角色A = 达妮娅，日常叫娅娅）：

```text
“达妮娅 / 娅娅” → 语义索引 → anima-000040（2.9B 底模自动换 29B/anima-000040_29b）
               → exact 身份绑定 denia_(wuthering_waves)
               → 激活词注入提示词
```

三条铁律：
1. **声明即权威**：编译期确认过的角色（哪怕最终提示词没写角色名），绑定层照样放行；
2. **家族自动适配**：2.9B 底模自动用 `29B/..._29b` 变体，老底模自动用原版；
3. **歧义即拒绝**：一个 LoRA 绑定多个身份、或身份与声明不符，直接拦下不猜。

**追画不用重复角色名**：上一张成功的角色（身份 + LoRA + 激活词）会存进会话配方，
“重新画一张，去掉项链”会自动沿用角色A。想换人时，显式说新角色即可。

**批量适配 2.9B**：WebUI LoRA 页有“一键批量标记 29B 兼容”按钮，转换过的 LoRA
秒级建档（复制原版的触发词与元数据，不消耗 LLM 次数）。

> 注意：把原版 LoRA 转换出 `_29b` 变体的**转换工具不在本插件内，请自行查找**；
> 插件负责的是转换完成后的登记、建档与底模自动适配。

## 4. 出图同步现实时间

设置开关：`出图同步现实时间`（默认开）。

- 中午出图自动补 `day`，晚上补 `night`，傍晚补 `sunset`；
- 提示词里**已经写了时间**、或消息里提到“晚上/明天”等，则以你为准，不覆盖；
- 只补“光线时段”，不动场景内容。

## 5. 命令全表

| 命令 | 作用 |
|---|---|
| `/画图 <描述>` | 直接出图；加 `--llm` 让导演扩写，`--llm u` 更华丽 |
| `/画图no <描述>` | 同上，但以普通图片消息发送（不用合并转发） |
| `/重绘 角色是角色A <改动>` | 整图语义改图；`--mode preserve/balanced/free` 控制保留程度 |
| `/改图 ...` | 局部重绘入口（配合蒙版） |
| `/换角色 角色A -> 角色B --preset 风格` | 精确换角，场景衣服保持 |
| `/底图控制 <要求> --m p/d/l/r` | 姿势 / 深度 / 线稿 / 参考图控制 |
| `/控制画图 <要求> --m p/d/l/r` | 底图控制 + 直接出图二合一 |
| `/反推` | 反推图片为 Tags |
| `/反推画图 <要求>` | 先反推再按你的要求出图 |
| `/放大` | RTX 独立放大 |
| `/方案`、`/方案列表` | Prompt Lab 保存的出图方案 |
| `/模型列表`、`/模型切换` | 查看 / 切换当前 UNET 底模 |
| `/保存风格 <名字> <LoRA串>` | 把当前风格栈存成预设 |
| `/lora组合列表`、`/lora组合保存`、`/lora组合删除` | 管理风格组合 |
| `/lora刷新`、`/lora下载` | 刷新清单 / 从 Civitai 下载 |
| `/status`、`/cancel`、`/ping` | 任务状态 / 取消 / 测试 ComfyUI 连通 |
| `/comfy帮助`、`/help` | 帮助 |

## 6. 报错速查：先看方括号

所有模型类报错都带责任标签：

| 报错开头 | 谁的问题 | 常见原因与处置 |
|---|---|---|
| 【绘图导演思考模型】 | 导演 LLM | 超时 / 被安全策略拒答 / 输出格式不对 → 换稳定模型 |
| 【图片反推多模态模型】 | 反推多模态 LLM | 不支持图片输入 / 超时 → 换视觉模型 |
| （无标签，本地校验类） | 环境或配置 | 按提示补文件 / 改配置 |

其余常见提示：

| 提示 | 含义 |
|---|---|
| `已明确选择的角色 LoRA 身份绑定…不一致或已失效` | LoRA 的绑定身份和消息里声明的角色对不上；检查 WebUI 绑定 |
| `PresetManifestError` | 最终标签清单与预期不一致，多见于 LoRA 名与底模族不匹配（新版已自动归一化） |
| `29B/xxx_29b 不存在 / 不可加载` | 转换产物不在 ComfyUI 的 LoRA 目录里；`_29b` 转换工具请自行准备 |
| 任务状态 `partial / output_ready` | 正常。QQ 不回执，插件诚实标注“输出就绪” |

## 7. WebUI 与任务中心

- 独立面板：`http://<host>:6198`（完整设置 + LoRA 视觉库 + 运行控制台）；
- AstrBot 原生插件页：AstrBot WebUI → 插件 → ComfyAnima（功能一致，走 AstrBot 鉴权）；
- 任务中心：每次出图的全过程阶段、失败原因、耗时、任务事件账本；
- 运行控制台：插件日志实时滚动（包括每次意图判断的结论）。

```text
不像角色 —— 查绑定：角色 / 作品 / 激活词，三样齐全再试

```
