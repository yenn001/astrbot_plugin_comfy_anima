# ComfyAnima 进阶指南（人话版）

这份文档写给已经能用基础命令、想玩得更细的人。
不会出现“fail-closed”“terminal trace”这种词，只说现象和怎么用。

---

## 1. 三条出图路径，先搞清楚

| 路径 | 触发方式 | 适合场景 |
|---|---|---|
| 直接 Tags | `/画图 ...` | 你知道自己要什么，不想等模型扩写 |
| LLM 导演 | `/画图 --llm ...` 或自然语言“帮我画……” | 你只说感觉，让模型组织画面 |
| 自然语言 | “我想看娅娅的照片” | 聊天中顺便出图 |

**区别**：
- 直接 Tags：你的文字原样进 ComfyUI，速度快；
- LLM 导演：先让模型理解，再输出结构化提示词，慢一点但更懂人话；
- 自然语言：Bot 先正常回复，再异步补图，最适合日常聊天。

---

## 2. 角色 LoRA 和“像不像”这件事

角色像不像，取决于三样东西：

1. **LoRA 文件**：`denia_lorav4-000005` 这种，负责脸和身体特征；
2. **激活词**：LoRA 需要 prompt 里写对触发词才生效，比如 `denia (wuthering waves)`；
3. **语义索引**：插件本地保存的“这个 LoRA 是谁、有哪些别名、属于哪部作品”。

如果画出来不像：

```text
1. WebUI → LoRA 详情，看角色、作品、激活词有没有填；
2. 没填就补上并保存；
3. 然后用明确写法重试：角色是达妮娅
```

## 3. 风格预设和“风格006”是什么

风格预设是一组 LoRA 的快捷方式。

```text
/画图 风格006 达妮娅
```

意思是：

```text
加载“风格006”这组风格 LoRA + 识别“达妮娅”这个角色
```

你可以在 WebUI 里：
- 看每个预设里到底有哪些 LoRA；
- 新建 / 修改 / 删除预设；
- 给角色预设写死衣服、身份锚点和触发词。

---

## 4. 换角色：两种写法的差别

**写法 A（推荐，最稳）**
```text
先发一张图，然后回复图片：
/换角色 原图角色 -> 达妮娅 --preset 风格006
```

**写法 B（自然一点）**
```text
/重绘 角色是 kei（blue archive）
```

A 走精确换角，只换人，场景衣服尽量保持；
B 走整图改图，由模型理解“改成谁”。

> 当前版本已知坑：`/重绘 风格006 角色换成达妮娅` 会把“风格006”误当角色来源，掉进错误的导演路径。用 A 或“角色是达妮娅”即可。

## 5. 底图控制：让姿势听你的

```text
先发一张参考图，然后：
/底图控制 构图和姿势不变 --m p
```

| 参数 | 含义 |
|---|---|
| `--m p` | 姿势 Pose |
| `--m d` | 深度 Depth |
| `--m l` | 线稿 Lineart |
| `--m r` | 参考 Reference |
| `--m p d` | 多个控制一起用 |

控制图只锁几何/构图，不锁脸和衣服。

---

## 6. 图片反推

```text
先发图，然后：
/反推
```

Bot 会返回它从图里看到的 Tags。

```text
/反推画图 换个表情
```

则先反推，再按你的要求画一张新的。

## 7. 三个模型，各管什么

| 模型 | 干什么 | 注意 |
|---|---|---|
| 绘图导演 | 把“达妮娅自拍”扩写成完整提示词 | 必须能输出插件要求的结构 |
| 图片反推 | 看图说 Tags | 必须支持图片输入 |
| 意图判断 | 判断聊天是否要出图 | 不能和上面两个相同 |

**推荐组合**（当前验证过）：
```text
绘图导演：DeepSeek V4 Flash Vision 或 DeepSeek V4 Pro
图片反推：DeepSeek V4 Flash Vision
意图判断：留空或另选一个便宜小模型
```

## 8. 任务为什么是 partial / output_ready

生成成功、图片文件也已就绪，但 QQ 平台不返回 `message_id`，插件无法机器确认对方是否收到。

插件选择诚实：
```text
任务终态 = partial / output_ready
意思是：图片已生成，发送状态未知
```

这是设计决定，不是 bug。

---

## 9. 2.9B 是什么情况

- 本版本只支持 Legacy 模型资产；
- 明确属于 2.9B 的 LoRA / 模型会被拒绝；
- 没有声明家族的 LoRA 在 Legacy 下按 Legacy 使用；
- 完整 2.9B 支持在后续版本。

## 10. 调试口诀

```text
出图失败 → 看 Bot 回复的错误码
改图失败 → 先确认发了图片、反推模型支持图片
不像角色 → 查 LoRA 详情 + 触发词
超时     → 换 DeepSeek 系模型
不确定   → /comfy帮助
```

再不行就去 WebUI 日志页，把最近的红色日志发出来。
