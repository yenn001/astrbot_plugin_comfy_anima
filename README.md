# AstrBot ComfyAnima 插件 v2.4.3

让 AstrBot 里的角色真的能“画图”的插件。
接上 ComfyUI 之后，在 QQ 里说一句话就行。

> 当前版本：**2.4.3**（内部构建 3.1.429）

> 下文用 **角色A** 指代你在插件里绑定过的任意角色（比如达妮娅，日常叫娅娅）。

---

## v2.4.3 更新了什么

- 🪜 **放大分三档**：底图直出 / RTX 放大 / RTX + TTP 瓦片细节增强，在设置里
  一键切换。TTP 档会把放大后的图切块、逐块用 AI 重画细节再拼回去——发丝、
  蕾丝、裙褶是"真细节"不是"糊出来的高清"。代价是耗时变成纯 RTX 的 3-5 倍
  （5090 上约 2 分钟一张），日常聊天嫌慢就关掉，重要出图再开；
- 🚫 **动嘴就能管住画面**：
  - "**这次**别画项圈" → 只这一张不画；
  - "**以后都别画**项圈" → 角色会用自己的口吻跟你确认，之后每张图都不画，
    直到你说"可以画项圈了"为止（也可以用 /别画、/解禁 命令）；
  - 设置里还能填**全局附加正/负词**，对所有角色所有会话生效；
- 🎛 **采样参数能调了**：CFG、采样器、调度器以前焊死在工作流里，现在设置里
  就能覆盖（0/留空 = 用工作流原值，默认不干预）；
- 🖐 **重绘不再"改着改着换人"**：对插件自己发的图做 /重绘、/底图控制时，
  自动沿用会话的角色 LoRA 和负面池，并通过角色一致性审计；别人的图不强套；
- 🧼 **修了一堆交付毛病**：聊天里不会再漏出 `<lora:...>` 标签和整段英文
  提示词了；"别画X"现在是确定性生效（不再依赖模型自觉）；角色也不会突然
  冒出"本角色基于公开资料蒸馏"之类的免责声明；
- 🪞 **两个控制台长一个样**：AstrBot 插件页和 6198 端口的独立控制台此前会
  各改各的，现在强制同源，设置两边随便用哪个都一样；
- 🧹 升级后旧会话配方会清空一次（先成功画一张即可恢复续画和粘性禁令）。

## v2.4.2 更新了什么（历史）

- 📦 **聊天记录里的图不再空白**：以前角色用"合并转发"一次发多图，QQ 点开
  聊天记录是空的。现在转发的每张图都能正常显示（NapCat 请更新到 4.18.19 及以上）；
- 💬 **角色会主动"画给你看"**：聊天里角色说了"给你看""拍给你看"这类话，
  插件会真的把那句话里的画面画出来，图片就长在她这条消息里——不用再喊一遍。
  这个功能默认关，且只对你在 AstrBot 里设置的管理员会话生效；
- ⚙️ **四个新开关**：开不开"主动画给你看"、同一个会话多久能画一次、用什么
  判定后端、哪些话算"交付语"，都能在插件设置或 Web 控制台里改；
- 🧠 **模型选择放宽**：意图判断模型可以和绘图导演用同一个了。

> 小提醒：升级到 2.4.2 后，先让角色成功画出一张图，"主动画给你看"才会激活
> （它需要一张"画对了"的底样来锁定角色长相，防止凭空画成别人）。

## 它能干什么

- 🎨 **聊天出图**：像平时说话一样，“想看角色A穿JK制服”，图就来了；
- ✏️ **改图重绘**：发一张图，“重新画一张，去掉项链”，它照做；
- 👤 **换角色**：图里的角色A换成角色B，姿势和场景保持不变；
- 🖼 **照着参考图画**：给一张图，让它按姿势 / 深度 / 线稿来画；
- 🎨 **换画风**：一堆现成风格组合（写实、油画、厚涂…），说名字就换；
- 🔍 **看图说话**：发图给它，它告诉你图里有什么；
- ⏰ **跟着现实时间走**：中午聊天图里就是白天，晚上自动夜景；
- 🌙 **2.9B / 老版模型都行**：换底模不用重配，LoRA 自动适配
  （`_29b` 转换工具请自行查找，插件负责转换后的登记与建档）。

## 三步开始

1. **装插件**：AstrBot WebUI → 插件页 → 搜 ComfyAnima → 安装；
2. **填地址**：插件设置里填你的 ComfyUI 地址（比如 `http://127.0.0.1:8188`）；
3. **绑定角色**：WebUI → LoRA 详情，把角色 / 作品 / 激活词填好（比如角色A = 达妮娅）；
4. **说句话**：`画一张角色A的自拍` —— 完事。

> 手动安装：从 [Releases](https://github.com/yenn001/astrbot_plugin_comfy_anima/releases) 下载 ZIP，
> 解压到 `AstrBot/data/plugins/` 后重启 AstrBot。

## 你可以直接这样说

把“角色A”换成你的角色名（比如达妮娅 / 娅娅）：

```text
画一张角色A的自拍
想看角色A穿JK制服，画出来给我看
重新画一张，把项链去掉
把这张图的角色A换成角色B
```

也支持命令（更精确）：

| 你想干嘛 | 命令 |
|---|---|
| 直接出图 | `/画图 角色A自拍` |
| 让 LLM 帮你想提示词 | `/画图 --llm 角色A自拍` |
| 按风格出图 | `/画图 风格001-29b 角色A` |
| 发图后改图 | 回复图片：`/重绘 角色是角色A` |
| 照姿势画 | 回复图片：`/底图控制 保持姿势 --m p` |
| 看所有命令 | `/comfy帮助` |

## 出问题时

- **报错带【绘图导演思考模型】或【图片反推多模态模型】**——方括号里就是出问题的模型，
  去设置里换一个稳定的就行（导演推荐 DeepSeek 系列）；
- **画出来不像角色A**——WebUI → LoRA 详情，把角色 / 作品 / 激活词补全，再说一次；
- **普通聊天突然出图了 / 该出图没出**——设置里“自然语言绘图模式”调成“完整自然绘图”；
- **报 `29B/xxx_29b` 不存在 / 不可加载**——先确认这个转换产物真的在 ComfyUI 的
  LoRA 目录里（`_29b` 转换工具请自行查找）。
