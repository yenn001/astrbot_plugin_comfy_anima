# AstrBot ComfyAnima 插件 v2.5.0

让 AstrBot 里的角色真的能“画图”的插件。
接上 ComfyUI 之后，在 QQ 里说一句话就行。

> 当前版本：**2.5.0**（内部构建 3.1.459）

> 下文用 **角色A** 指代你在插件里绑定过的任意角色（比如达妮娅，日常叫娅娅）。

---

## v2.5.0 更新了什么

这一版重点在**“她知道自己是画里的谁”**和**“设置真的是能改的”**两件事上。

### 🎭 她知道自己是角色A了

以前她画自己，靠的是“猜”——你在对话里提到谁，她就画谁，没提到就容易飘。
现在可以在设置里直接**绑定她自己的角色**：

- 设置里填上角色预设名（比如 `达妮娅`），之后**你没点名别的角色**时，
  出图自动套用她的角色预设：身份锚点、触发词、角色 LoRA 一次到位；
- 你**明确点了别的角色**、或用了换角命令，绑定自动让位，不会抢你的话；
- 想更细可以按会话/平台分别绑定（`作用域覆盖`），比如群聊和私聊用不同角色；
- 填错预设名不会静默失败——**保存时就会拒绝并列出可用的角色预设**给你挑。

### 🔇 一次出图只说一句话

以前她一边查资料一边说话，一次出图能蹦出三四句差不多的话。现在出图过程中的
中间轮次会静默，**你只会收到最终那一条带图的消息**（这个开关在设置里，
默认关闭，想听她边画边聊可以开回来）。

### 🎛 设置终于是“真的能改”了

- **修好 4 个“看着能改、其实存不进去”的开关**：以前“按 Bot 回复意图续画”
  那一组的四个控件，在控制台里改了保存后会被**静默丢弃**，现在真的生效了；
- **新增 45 个设置控件**：生成与超时（轮询间隔、出图总超时、HTTP 超时）、
  行为开关（会话配方续画、清单闸门、并行预检、视觉意图识别…）、
  场景提取、LoRA 检索上限、分群放行等级等，以前只能去 AstrBot 原生插件页
  找，现在独立控制台里就有；
- **清掉 5 个“改了也没用”的配置项**：它们只在配置文件里存在、代码从不读取，
  留着只会让人以为“我已经配好了”；
- 顺手加了防复发测试：**界面上能改的每一个控件，都必须真的能存**——
  这类问题以后不会再悄悄出现。

### 🎨 控制台多了两套皮肤

设置 → 右上角「界面主题」，现在有 5 种可选：

- **暗色霓虹**：深色玻璃质感 + 青紫渐变，长时间盯图不刺眼；
- **密集终端**：全局等宽字体、紧凑排版，一屏看最多配置；
- 原有三套（纸感工坊 / 铅灰编辑部 / 墨夜控制室）保留不变。

选择记在浏览器里，切换立即生效、不用重启。

### 🖌 出图更“有东西”

Anima 这类模型，**提示词里的 tag 串决定了画面有多少细节**。实测本插件此前的
tag 串长期在及格线上下（中位数 22.5，**23% 的图不足 20 个**）。这一版：

- 提示词里明确了 tag 串下限与分配：身份 ≥3、**服装（含饰品，从上到下）≥5**、
  动作 ≥2、镜头 ≥2、场景 ≥2、主光 ≥2，**只设下限不设上限**；
- 下限本身也是可调的设置项（`tag 串下限`，默认 20，填 0 关闭）；
- 现在每次出图的 tag 数会记录在任务事件里，方便你/我核对效果。

### 👗 说了“吊带”就真的画吊带

以前你说“**吊带丝袜**”，翻译环节会把它当成普通“丝袜”，**“吊带”两个字在第一步就丢了**，
所以画出来只有连裤袜、没有吊带结构。现在补全了这类说法：

| 你说 | 现在译成 |
|---|---|
| 吊带袜 / 吊带丝袜 / 吊带长筒袜 / 蕾丝吊带袜 | `garter straps, thighhighs` |
| 过膝袜 / 长筒袜 | `thighhighs` |
| 连裤袜 / 丝袜 / 黑丝 | `pantyhose` / `black pantyhose` |

### 👀 “掀开给我看”这类要求真的会被照做

以前提示词只管“画什么”，不管“看不看得见”——所以“穿着吊带袜 + 穿着长睡裙”
在文字上完全成立，但**裙下的东西根本看不见**。现在构图规则里加了**可见性要求**：
你点名要看的部位或服饰若被外层衣物遮住，必须用能露出它的构图与动作
（掀起 / 撩开 / 褪下 / 敞开），并写出对应的可见性 tag（`skirt lift`、`clothes lift` 等）；
点名局部时优先半身或局部特写，不用全景把细节稀释掉。

> 已知待办：若一句话里**同时**提到“裤袜”和“吊带袜”，目前可能出现两者叠穿
> （腿部穿着还没有互斥规则）。已在计划内。

### 👤 重绘时自动补角色外貌（按 Danbooru）

点名角色之后（例如“角色是 toki_(Blue_Archive)”），插件会去查这个角色的**稳定外貌特征**
（比如 `blonde hair`、`halo`），并要求导演**必须**把它们写进提示词——
这样她就不是“照着原图猜长相”，而是按这个角色公认的样子画。

- 外貌证据来自 Danbooru 公开帖子的**共现统计**（有支持率与样本数门槛）；
  **样本不足就宁可不补、也不猜**；
- **不需要 LoRA**：本地没有这个角色的 LoRA，也照样查；
- **有 LoRA 时两者并存**（LoRA 触发词 + 外貌特征），互不冲突；
- 外貌证据有缓存：过期只代表“该刷新了”，**不代表失效**——旧证据照常使用，刷新在后台进行，
  所以不会为了等网络而卡住出图。

> ⚠️ **已知问题（正在修）**：这条链路**目前主要在你手动补充时才稳** ——
> “角色是 toki_(Blue_Archive)”这种写法里，角色名在解析时**会被截断**
> （变成 `archive)`，或从描述文字里误抓成 `background`），于是查询落空、外貌没进提示词。
> **临时办法**：直接把外貌写进要求，例如“**金发、蓝瞳、有光环**，穿兔女郎装”。

### 🖌 重绘强度按实测重排（三档）

以前重绘的三档强度默认值**不实用**：平衡档（0.55）**改不动发色**这类外观特征，
自由档（0.78）能改却几乎等于重画、**构图必跑**。现在按实测数据重排：

| 档位 | 强度 | 适合什么 |
|---|---|---|
| `--m preserve`（严格） | 0.55 | 只动你点名的那一处，其余尽量保留 |
| `--m b`（平衡，默认） | **0.62** | 改发色 / 换装这类看得见的变更，同时守住构图 |
| `--m f`（自由） | **0.70** | 需要更大自由度地重画 |

- 想更精细可以**单独指定强度**：`--denoise 0.66`（或 `--d 0.66`）——
  它**优先级最高**，会覆盖档位默认值；
- 要求里含“换装 / 改姿势 / 改构图”等**大改**关键词时，三档都会被抬到 **0.64**，
  保证“画得动”。这是**刻意的设计**，想压回去就显式写 `--d 0.62`。

### 🔧 顺带修掉的重绘毛病

这几条都是排查“重绘时好时坏”时定位并修掉的：

- **时好时坏**：模型偶尔会在提示词标签后多吐一个 `</p>`（或 `</pic>`），
  以前会被判成“格式不合法”而**整张不出图**；现在会先剥掉这类**无信息量的包裹噪声**，
  而标签外真有文字时**依旧会失败**（不放松校验）；
- **失败时看不到原因**：以前只留一个错误类型；现在会记录**模型响应的原文（含结尾）**
  与**具体失败分支**，一眼可查；
- **过期不等于失效**：角色外貌证据过期后以前会被整条丢弃；现在**照常使用**并在后台刷新；
- **接口错误不再被当成数据**：Danbooru 图库连不上站点时会返回一条错误，以前会被
  当成“只取到 1 条帖子”，于是报成“样本不足”；现在会**如实报出连接错误**。

## v2.4.3 更新了什么（历史）

- 🪜 **放大分三档**：底图直出 / RTX 放大 / RTX + TTP 瓦片细节增强，在设置里
  一键切换。TTP 档会把放大后的图切块、逐块用 AI 重画细节再拼回去——发丝、
  蕾丝、裙褶是"真细节"不是"糊出来的高清"。代价是耗时变成纯 RTX 的 3-5 倍
  （5090 上约 2 分钟一张），日常聊天嫌慢就关掉，重要出图再开；
- 🚫 **动嘴就能管住画面**：
  - "**这次**别画项圈" → 只这一张不画；
  - "**以后都别画**项圈" → 角色会用自己的口吻跟你确认，之后每张图都不画，
    直到你说"可以画项圈了"为止（也可以用 /别画、/解禁 命令）；
  - 设置里还能填**全局附加正/负词**，对所有角色所有会话生效；
- 🎛 **采样参数能调了**：CFG、采样器、调度器以前焊死在工作流里，现在设置里
  就能覆盖（0/留空 = 用工作流原值，默认不干预）；
- 🖐 **重绘不再"改着改着换人"**：对插件自己发的图做 /重绘、/底图控制时，
  自动沿用会话的角色 LoRA 和负面池，并通过角色一致性审计；别人的图不强套；
- 🧼 **修了一堆交付毛病**：聊天里不会再漏出 `<lora:...>` 标签和整段英文
  提示词了；"别画X"现在是确定性生效（不再依赖模型自觉）；角色也不会突然
  冒出"本角色基于公开资料蒸馏"之类的免责声明；
- 🪞 **两个控制台长一个样**：AstrBot 插件页和 6198 端口的独立控制台此前会
  各改各的，现在强制同源，设置两边随便用哪个都一样；
- 🧹 升级后旧会话配方会清空一次（先成功画一张即可恢复续画和粘性禁令）。

## v2.4.2 更新了什么（历史）

- 📦 **聊天记录里的图不再空白**：以前角色用"合并转发"一次发多图，QQ 点开
  聊天记录是空的。现在转发的每张图都能正常显示（NapCat 请更新到 4.18.19 及以上）；
- 💬 **角色会主动"画给你看"**：聊天里角色说了"给你看""拍给你看"这类话，
  插件会真的把那句话里的画面画出来，图片就长在她这条消息里——不用再喊一遍。
  这个功能默认关，且只对你在 AstrBot 里设置的管理员会话生效；
- ⚙️ **四个新开关**：开不开"主动画给你看"、同一个会话多久能画一次、用什么
  判定后端、哪些话算"交付语"，都能在插件设置或 Web 控制台里改；
- 🧠 **模型选择放宽**：意图判断模型可以和绘图导演用同一个了。

> 小提醒：升级到 2.4.2 后，先让角色成功画出一张图，"主动画给你看"才会激活
> （它需要一张"画对了"的底样来锁定角色长相，防止凭空画成别人）。

## 它能干什么

- 🎨 **聊天出图**：像平时说话一样，“想看角色A穿JK制服”，图就来了；
- 🎭 **她有自己的身份**：设置里绑定一次，之后她画自己就是自己，不用每次点名；
- ✏️ **改图重绘**：发一张图，“重新画一张，去掉项链”，它照做；
- 👤 **换角色**：图里的角色A换成角色B，姿势和场景保持不变；
- 🖼 **照着参考图画**：给一张图，让它按姿势 / 深度 / 线稿来画；
- 🎨 **换画风**：一堆现成风格组合（写实、油画、厚涂…），说名字就换；
- 🔍 **看图说话**：发图给它，它告诉你图里有什么；
- ⏰ **跟着现实时间走**：中午聊天图里就是白天，晚上自动夜景；
- 🌙 **2.9B / 老版模型都行**：换底模不用重配，LoRA 自动适配
  （`_29b` 转换工具请自行查找，插件负责转换后的登记与建档）。

## 三步开始

1. **装插件**：AstrBot WebUI → 插件页 → 搜 ComfyAnima → 安装；
2. **填地址**：插件设置里填你的 ComfyUI 地址（比如 `http://127.0.0.1:8188`）；
3. **绑定角色**：WebUI → LoRA 详情，把角色 / 作品 / 激活词填好（比如角色A = 达妮娅）；
4. **绑定她自己的角色**（v2.5.0 新增，推荐）：设置 → 「BOT 角色绑定」里填角色预设名，
   之后不点名也能画对自己；
5. **说句话**：`画一张角色A的自拍` —— 完事。

> 手动安装：从 [Releases](https://github.com/yenn001/astrbot_plugin_comfy_anima/releases) 下载 ZIP，
> 解压到 `AstrBot/data/plugins/` 后重启 AstrBot。

## 你可以直接这样说

把“角色A”换成你的角色名（比如达妮娅 / 娅娅）：

```text
画一张角色A的自拍
想看角色A穿JK制服，画出来给我看
想看角色A穿吊带丝袜，画出来
裙摆下面也要看得见，掀开一点画给我看
重新画一张，把项链去掉
把这张图的角色A换成角色B
```

也支持命令（更精确）：

| 你想干嘛 | 命令 |
|---|---|
| 直接出图 | `/画图 角色A自拍` |
| 让 LLM 帮你想提示词 | `/画图 --llm 角色A自拍` |
| 按风格出图 | `/画图 风格001-29b 角色A` |
| 发图后改图 | 回复图片：`/重绘 角色是角色A` |
| 重绘·严格（少改） | 回复图片：`/重绘 --m preserve 角色是角色A` |
| 重绘·自由（大改） | 回复图片：`/重绘 --m f 角色是角色A` |
| 指定重绘强度 | 加上 `--denoise 0.66`（或 `--d 0.66`，**优先级最高**） |
| 照姿势画 | 回复图片：`/底图控制 保持姿势 --m p` |
| 看所有命令 | `/comfy帮助` |

## 设置写在哪儿

三个地方都能改，**改的是同一份配置**：

1. **AstrBot 插件页**：自动列出全部配置项（最全）；
2. **独立控制台**（默认 `6198` 端口）：按主题分组的可视化面板，带 45+ 个常用控件、
   任务中心、LoRA 管理、风格与角色串、Prompt Lab 等；
3. 直接改 `config/astrbot_plugin_comfy_anima_config.json`（不推荐）。

改完保存后插件会自动重载，不用手动重启。

## 出问题时

- **报错带【绘图导演思考模型】或【图片反推多模态模型】**——方括号里就是出问题的模型，
  去设置里换一个稳定的就行（导演推荐 DeepSeek 系列）；
- **画出来不像角色A**——WebUI → LoRA 详情，把角色 / 作品 / 激活词补全；
  若她已经绑定过自己的角色预设（v2.5.0），检查设置里的绑定是否填对；
- **设置了但好像没生效**——先看设置里的「tag 串下限」「自然语言绘图模式」
  这类开关是否被别的项覆盖；控制台保存后会提示“设置已保存，插件即将自动重载”；
- **普通聊天突然出图了 / 该出图没出**——设置里“自然语言绘图模式”调成“完整自然绘图”；
- **报 `29B/xxx_29b` 不存在 / 不可加载**——先确认这个转换产物真的在 ComfyUI 的
  LoRA 目录里（`_29b` 转换工具请自行查找）；
- **重绘改不动发色 / 换不掉某个特征**——先用 `--m f`（0.70）或显式 `--d 0.7` 试；
  仍不行就是 img2img 的固有约束（原图占比越大越难改），需要局部精修请用**蒙版局部重绘**；
- **重绘后构图跑偏**——`--m f` 的提示词**允许**重排构图；想守住构图请用 `--m b`
  （0.62）或 `--m preserve`（0.55）；
- **重绘抱怨“样本不足”**——那是插件**不肯猜**（Danbooru 公开样本或支持率不够）。
  若你已知道该角色长什么样，直接把特征写进要求最快。
